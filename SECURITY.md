# Security Policy

## Reporting Security Issues

We take the security of VaelMail very seriously. If you have discovered a vulnerability or security concern, please report it to our security team.

### Contact
* Email: contact@vael.email
* Web: https://vaelmail.com/contact
* Security Advisory Specification: https://vaelmail.com/.well-known/security.txt

### Response Timeline
* Initial acknowledgement within 24 hours.
* Remediation timeline provided within 72 hours.
* Coordinated public disclosure following fix deployment.
